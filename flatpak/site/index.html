Vos fichiers, entre le PC et le téléphone.

Brise envoie fichiers, photos, textes et liens entre votre PC Linux et n’importe quel téléphone, iPhone ou Android. Rien à installer sur le téléphone : il scanne un QR code et c’est tout.

Installer avec Flatpak .deb, .rpm, AppImage
En un clic

Logiciels de GNOME ou Discover

Le bouton « Installer avec Flatpak » ouvre Brise dans votre logithèque, qui l’installe et ajoute ce dépôt pour les mises à jour.

Dans un terminal

Installer

flatpak install --user https://belzeeebuth.github.io/brise/io.github.belzeeebuth.brise.flatpakref
Ou par le dépôt

Ajouter le dépôt Brise

flatpak remote-add --user --if-not-exists brise https://belzeeebuth.github.io/brise/brise.flatpakrepo
flatpak install --user brise io.github.belzeeebuth.brise
Mises à jour : flatpak update, ou automatiquement par votre logithèque. Pare-feu : Brise reçoit le téléphone sur le port 53318/TCP ; autorisez-le si le téléphone n’arrive pas à se connecter. Signature : le dépôt est signé avec la clé 9901 F920 0D0F 7813 A955 2C36 461E 1ADF 26B8 993B (clé publique). In English: Brise shares files, photos and text between a Linux computer and any phone, with nothing to install on the phone. Install it with the commands above.
